# Everyone needs a verified Account; there are no guests

An earlier idea let guests join a Room with only the Room ID and a display name. We decided every Member must have a verified Account (email, password, emailed code) with a unique permanent Username instead. Debts must outlive a browser session, so a guest identity tied to a browser token could not be trusted with money records. Accounts also make leaving and rejoining restore the same Member, and make Usernames unambiguous in the audit log. The cost is more friction when joining a Room.
